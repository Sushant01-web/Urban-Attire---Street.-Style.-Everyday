/\*-------------------------------------------------------------------------

Steps to Create any Logic like for adding product, address and More

--------------------------------------------------------------------------/\*

----This is in Backend

1. Build Mongoose Schema for it in Models folder which is in server

2. Write Controller for that schema

3. Write a different routes for different controller

4. specify Endpoint to fetch that route in Server

----Now in Front-end

1. Create Slice and Asyncthunk for that logic in our Store folder

2. import that slice and asyncthunk in our store
